## JSON Schema Reference

Each `.json` file contains the following fields:

### Core Fields

| Field               | Type   | Description                                |
| ------------------- | ------ | ------------------------------------------ |
| `song_id`           | string | Unique identifier (lowercase, underscores) |
| `filename`          | string | Original audio filename                    |
| `bpm`               | number | Tempo in beats per minute                  |
| `beats_per_measure` | number | Time signature (typically 4)               |

### Timing Arrays

| Field            | Type     | Description                             |
| ---------------- | -------- | --------------------------------------- |
| `beats`          | number[] | Timestamp (seconds) of every beat       |
| `downbeats`      | number[] | Timestamp of beat 1 of each measure     |
| `beat_drop_time` | number   | When the main rhythm kicks in (seconds) |

### Metadata

| Field        | Type         | Description                     |
| ------------ | ------------ | ------------------------------- |
| `duration`   | number       | Total song length in seconds    |
| `confidence` | number       | Detection reliability (0.0-1.0) |
| `end_time`   | number\|null | Optional end marker for looping |

## FreestyleFlow Integration

### How to Use

1. Copy the `.json` files to your FreestyleFlow `beat-data/` directory
2. Ensure the `filename` field matches the actual audio file name
3. The app will use `beats[]` for rhythm sync and `beat_drop_time` for session start

### Key Fields for the App

- **`beats[]`** - Use for visual beat indicators and rhythm scoring
- **`downbeats[]`** - Use for measure boundaries (every 4th beat emphasis)
- **`beat_drop_time`** - Start freestyle sessions here (skips intros)
- **`bpm`** - Display tempo to user, adjust game difficulty

### Beat Drop Notes

The `beat_drop_time` indicates when the main beat kicks in. Some songs have:

- **Immediate drop** (< 1s): Track starts with full rhythm
- **Short intro** (1-5s): Brief buildup before main beat
- **Long intro** (> 10s): Extended atmospheric intro

### Common Issues to Check

1. **Beat drop timing** - May need manual adjustment for some tracks
2. **Downbeat phase** - First downbeat should align with musical "1"
3. **Fast tracks** - BPM is auto-normalized; verify tracks >165 BPM are correct
